## Why the runs failed

- **Tool calls are no longer emitted as text.**
  - None of the 700 responses contains `<tool_call>` as text, and every call came back as a structured `tool_calls`
    entry.
  - goinfer's "tool calls are not constrained for these tools" line appears zero times in both serve logs.
  - The first run's defect is gone. In it, two runs had ended on a call emitted as text, and a third on text that
    looked like one.
- **The 7B stops without editing.** 13 of 20 runs leave an empty diff. Most ended on `finish_reason: stop` after a
  reply in prose that does one of these:
  - writes the code into the answer ("we need to add the following code: …", task 1 A0);
  - summarises what it found (task 5 A0, tasks 7, 9 and 10 A0k);
  - declares the work already done ("No additional changes are needed", task 6 A0; "already set within the desired
    range", task 4 A0).
- **Loops.** Task 9 A0 called `glob` 359 times until the cap. Task 3 A0k sent 149 requests.
- **Edits that do not build or pass.** Tasks 1 A0k, 2 (both arms), 3 A0, 4 A0k and 11 (both arms) changed files, and
  the oracle failed to build or failed. Task 2's main session recorded no tool calls, so how its 517-byte diff was
  made is not yet checked.
