## Why

- **Qwen2.5-Coder-7B-Instruct does not call tools once it is offered several.**
  - In smoke it made no tool call on any of the 20 tasks, in either run. Its two passes are the two tasks where
    calling no tool is the right answer.
  - goinfer's `check` shows the boundary:
    - with one tool it calls it (`get_weather`, 2 turns);
    - with the 12-tool schema it answers without calling ("too small for tool use, or its template has no tool
      section"), on both `/v1/chat/completions` and `/v1/messages`.
  - Its template is not the cause. Its GGUF carries the same tool section (`{%- if tools %}`, `<tool_call>`) as the
    incumbent's, and the incumbent calls the tool among 12 and scores 18/20.
  - Its speed is the incumbent's, 85.6 tok/s against 85.7. Coder tuning cost it tool use, not speed.
- **Seed-Coder-8B-Instruct has no tool-calling template.**
  - Its GGUF holds no tool section, and goinfer answers every request that carries tools with `400 this model has no
    tool-calling template`.
  - So smoke scored 0 in 11 ms and every TTFT request failed, which made the arm void.
  - It is the same failure that retired phi3-mini-4k (amendment 5). Retiring it likewise is the owner's call.

## Decode audit (2026-10-18, corrected the same day)

**How E0's decode probe worked until tack `38137f5`** (`internal/eval/runner.go:decodeOnce`):

- like every tack request, it sent thinking disabled (`internal/server/goinfer/client.go:toWire`);
- it divided every output token the server counted by the time between the first and last streamed delta.

**When that inflates a rate.** goinfer turns thinking off for such a request (`resolveThink`), and drops reasoning that
reaches it anyway. So tokens were counted but not timed only when a model reasoned regardless:

- a template whose reasoning cannot be turned off (Harmony: gpt-oss, whose figure is withdrawn);
- a managed template that reasoned despite the off switch.

A template goinfer does not manage (`thinking: unmanaged` in its load banner) is never split. Its reasoning, if any,
streams as text and is timed.

**No figure can be recomputed.** The raw stream and goinfer's request log for these runs were not kept: E0's servers
logged to a temporary directory.

**A correction to the first version.** It gave the reason for the two gemma-4 figures as "gemma-4's thinking is
unmanaged, so goinfer could drop its reasoning". That is backwards: unmanaged means goinfer never splits the reasoning
out, so it never drops it. The two figures stay marked unverified because they were not recomputed, not because a
mechanism is known. A re-measurement on the fixed probe waits until gemma-4 comes back through C1 (owner).

**The fixed probe** sends each arm's registered thinking setting, disabled unless the arm sets `probe_thinking` for a
model whose reasoning cannot be turned off. It times thinking and text alike, and refuses a reply that counted more
tokens than it streamed characters.
